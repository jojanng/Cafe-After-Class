# Coding guidance

Read [docs/art-direction.md](docs/art-direction.md) before changing the scene, camera, materials, typography, or scope.

This is a browser-local playable milestone built with Vite, vanilla JavaScript, and Three.js. Keep original geometry and local procedural materials; no external asset service is needed. Use `npm ci`, `npm run dev`, and `npm run build`. Review an actual browser render at desktop and mobile sizes after visual changes. Preserve the quiet study view. Explicit Look around mode supports bounded camera navigation; focus disables navigation. The owner has authorized the study/serve loop, queue, collection, bounded camera navigation, interior/exterior decoration, and a shop funded only by in-game earnings. Do not add accounts, a backend, coupons, real café branding, public integrations, or deployment. Keep deterministic rules in src/game.js and storage in src/storage.js. Run npm test and npm run build; use npm run test:browser with a preview server for browser verification. The current owner workflow is to commit and push verified milestones to develop. Never push main, force-push, open a PR, merge, or deploy without an explicit request.

Direct placement uses `src/placement-model.js` for snap surfaces, dimensions and service anchors. Keep those contracts independent of decorative meshes. Backstore derives unique placed/stored pieces from existing ownership and layout IDs; recipes belong only in Menu. Keep preview gestures separate from persisted Confirm and preserve camera-versus-object ownership. Run the placement browser checks after changing editing or pointer behavior.
